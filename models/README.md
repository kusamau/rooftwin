# models/

| Directory | Lesson | Content |
|---|---|---|
| `dtdl/` | 2 | DTDL v3 interfaces: Site, SolarArray, MpptChargeController, SmartShunt, BatteryBank (Components: 3 × Battery), Inverter. Validate with `docker/dtdl-validator`. |
| `aas/` | 2 | Asset Administration Shell JSON for the same assets, generated by `aas/generate_solar_aas.py`. Validate with `docker/aas-validator`. |
| `onnx/` | 6 | Exported ML models served from Java |

The DTDL files are the source of truth for the twin's runtime shape; the Java records in
`apps/twin-core/.../core/model` mirror them, and `DtdlConformanceTest` fails the build when they
drift. See `docs/architecture-choice.md` and `docs/information-model.md`.
